Privacy Policy

Kids Little Lessons Uploader
Last updated: November 11, 2026

Kids Little Lessons Uploader is a private tool used only by the owner of the Kids Little Lessons and This Is Your Sign To YouTube channels. It uploads videos the owner made to the owner's own channels. It is not offered to the public.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

  • The signed-in channel's ID and name, to confirm each video goes to the correct channel.
  • Permission to upload videos and set their thumbnails on that channel.

The tool does not read, collect or store data about viewers, subscribers, comments, other users or other channels.

What is stored and where

The Google sign-in token is stored only on the channel owner's own computer. The only YouTube information kept is the ID of each uploaded video, in a local project file. Nothing is sent to any third party, sold or shared.

Children

Kids Little Lessons videos are uploaded as "Made for Kids". The tool collects no information from anyone who watches the videos, children included.

Removing access

Access can be withdrawn at any time from the Google account's third-party access settings. The owner can delete the locally stored token at any time.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

Questions can be sent through the Kids Little Lessons channel.
